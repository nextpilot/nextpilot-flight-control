# 产品中心

NextPilot 提供一系列高性能、高可靠性的无人系统核心组件，覆盖飞行控制、大气传感、差分定位、仿真训练与无人机机体五大领域。

---

## 飞行控制器

<div class="grid cards" markdown>

- ![导航飞控计算机](05-flight-controller/imgs/标识-导航飞控.png){: style="height:160px;margin-bottom:0.5rem" }

    ---

    :material-memory: NP-FCC-H50 飞行控制计算机

    [NP-FCC-H50](05-flight-controller/01-NP-FCC-H50.md) 新一代高性能导航飞控计算机，集成双频RTK、三冗余IMU和工业级处理器，为无人系统提供精准的导航、制导与控制。

- ![大气数据计算机](09-air-data/imgs/标识-空速计.png){: style="height:160px;margin-bottom:0.5rem" }

    ---

    :material-gauge: NP-ADS-H50 大气数据计算机

    [NP-ADS-H50](09-air-data/01-NP-ADS-H50.md) 工业级数字空速计，内置高性能差压传感器与气压传感器，精确测量空速、气压高度与温度，采用航空连接器，稳定可靠。

- ![地面差分基准站](07-nav-pos/imgs/标识-基准站.png){: style="height:160px;margin-bottom:0.5rem" }

    ---

    :material-antenna: NP-BASE-H50 地面差分基准站

    [NP-BASE-H50](07-nav-pos/01-NP-RTK-BASE.md) 便携式地面差分基准站，支持RTCM差分数据输出，配合机载RTK模块实现厘米级动态定位精度，通信接口采用航空连接器，稳定可靠。
